# AnyStore - Система управления магазином

Настольное приложение на C# (Windows Forms) для управления магазином: пользователями, категориями товаров, товарами, закупками, продажами и транзакциями. Разработано в трехуровневой архитектуре (3-tier) в соответствии с учебным заданием.

## Описание

AnyStore - это информационная система для автоматизации работы небольшого магазина. Приложение позволяет вести учет пользователей, категорий товаров, товаров на складе, а также фиксировать операции закупки и продажи с последующим просмотром истории транзакций за выбранный период.

Приложение реализовано в трехуровневой архитектуре:

- Уровень представления (UI) - Windows Forms
- Уровень бизнес-логики (BLL) - валидация и правила
- Уровень доступа к данным (DAL) - SQL-запросы к MS SQL Server

## Архитектура

Проект разделен на три независимых проекта (Class Library + WinForms):

```bash
AnyStore.UI ---> AnyStore.BLL ---> AnyStore.DAL ---> SQL Server
(интерфейс) (логика) (данные) (БД)
```

Каждый уровень изолирован и общается только с соседним:

- AnyStore.UI ссылается на AnyStore.BLL
- AnyStore.BLL ссылается на AnyStore.DAL
- AnyStore.DAL работает напрямую с базой данных

## Модули и функции

1. Модуль "Пользователь"
   - Добавление новых пользователей
   - Обновление существующих пользователей
   - Удаление пользователей
   - Разграничение доступа (Admin / User)

2. Модуль "Категория"
   - Добавление категорий товаров
   - Обновление категорий
   - Удаление категорий (с проверкой наличия товаров)

3. Модуль "Товар"
   - Добавление товаров
   - Обновление товаров
   - Удаление товаров (с проверкой наличия транзакций)

4. Модуль "Закупки и продажи"
   - Закупка товаров у поставщиков (увеличение остатка)
   - Продажа товаров покупателям (уменьшение остатка)
   - Автоматический расчет суммы операции

5. Модуль "Транзакции"
   - Просмотр всех операций
   - Фильтрация по дате (с / по)
   - Фильтрация по типу (PURCHASE / SALE)

6. Модуль "Аутентификация"
   - Вход в систему по логину, паролю и типу пользователя
   - Блокировка модуля пользователей для роли User

## Установка и запуск

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/Kiwinze/anystore.git
cd anystore
```
### Шаг 2. Создание базы данных

1. Откройте SQL Server Management Studio
2. Подключитесь к вашему экземпляру SQL Server
3. Откройте файл Database/AnyStoreDB.sql
4. Выполните скрипт (F5)

Скрипт создаст:
- базу данных AnyStoreDB
- таблицы Users, Categories, Products, Transactions
- тестовые данные
- хранимые процедуры sp_LoginCheck и sp_TransactionsByPeriod

### Шаг 3. Настройка строки подключения

Откройте файл AnyStore.DAL/DbConnection.cs и измените строку подключения под свой SQL Server:
```C#
public static readonly string ConnectionString =
@"Data Source=.\SQLEXPRESS;Initial Catalog=AnyStoreDB;Integrated Security=True;";
```

Варианты:

| Сценарий | Строка подключения |
|----------|-------------------|
| Локальный экземпляр по умолчанию | Data Source=localhost;Initial Catalog=AnyStoreDB;Integrated Security=True; |
| Именованный экземпляр SQLEXPRESS | Data Source=.\SQLEXPRESS;Initial Catalog=AnyStoreDB;Integrated Security=True; |
| С логином и паролем | Data Source=localhost;Initial Catalog=AnyStoreDB;User ID=sa;Password=ваш_пароль; |

### Шаг 4. Открытие решения

1. Откройте файл AnyStore.sln в Visual Studio
2. Убедитесь, что все три проекта добавлены в решение:
   - AnyStore (UI)
   - AnyStore.BLL
   - AnyStore.DAL
3. Проверьте ссылки между проектами:
   - AnyStore -> AnyStore.BLL
   - AnyStore.BLL -> AnyStore.DAL

### Шаг 5. Назначение запускаемого проекта

1. В Solution Explorer нажмите правой кнопкой по проекту AnyStore
2. Выберите "Назначить запускаемым проектом" (Set as StartUp Project)
3. Название проекта станет жирным

### Шаг 6. Запуск

Нажмите F5 или зеленую кнопку "Start". Откроется форма входа.
